# Data Model: Memory Bridge

## Memory Payload
The payload generated by `export_proven_memory` and consumed by `commit_to_memory`.

| Field | Type | Description |
|-------|------|-------------|
| entities | array | Objects with `name`, `entityType`, `observations` |
| relations | array | Objects with `from`, `to`, `relationType` |

## Mapping Rules
- **Entity Name**: `node_[UUID]` or custom ID.
- **Entity Type**: "ReasoningNode".
- **Observations**: The `thought` content of the node.
- **Relations**: Map ThoughtGraph relations (`refinement`, `support`, etc.) to Memory relations.
