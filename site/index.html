16 Tools. One Engine.

From basic thought proposals to autonomous reasoning loops — every primitive from the Graph of Thoughts paper, implemented and production-ready.

🧠
propose_thought
Seed reasoning nodes with parent relations. Branch, refine, contradict, or support.
⚖️
evaluate_thought
Score 0.0–1.0, add critique, or omit score to trigger autonomous LLM audit via sampling.
⚡
aggregate_thoughts
Merge 2+ nodes via Σ(score×weight)/Σ(weights). Retains full provenance chain.
✂️
prune_branch
Hard or soft prune. BFS cascade with decay factors. Auto or manual trigger tracking.
🎯
find_winning_path
Greedy DFS or k-best beam search with score thresholds and path length caps.
🔬
reflect_and_refine
4-axis confidence vectors (factual, logical, relevance, novelty). Auto-branch on low scores.
📦
context_set / get / list
Shared context store with source provenance. CA-MCP pattern for cross-step knowledge.
📤
export_reasoning_trace
Long CoT format compatible with DeepSeek-R1 and o3 RL training pipelines.
🔄
run_controller_loop
Autonomous GoT orchestrator. Generate → Evaluate → Branch → Reflect → Prune → Converge. One call.
