## 🎯 Purpose

This repository hosts the **Master MCP Configuration** (`mcp_config.json`). This unified file is designed to be the single source of truth for your Model Context Protocol servers, compatible with modern AI-enabled development environments including **Cursor**, **Antigravity**, **VSCode (Roo Code/Cline)**, and **Kiro**.

## 📄 Standardized Schema

Based on the [Model Context Protocol Specification](https://modelcontextprotocol.io), the verified `mcpServers` configuration block follows this strict schema:

```json
{
  "mcpServers": {
    "server-name": {
      "command": "executable-name",  // e.g., "npx", "docker", "python"
      "args": ["arg1", "arg2"],      // Array of string arguments
      "env": {                       // Environment variables
        "KEY": "VALUE"
      }
    }
  }
}
```

> **Note:** Fields like `globalSettings`, `description`, and `notes` included in this file are extensions for human readability and advanced client handling (like Antigravity). Standard clients will simply ignore them.

## 🔌 IDE Integration Guide

### 1. Cursor / Kiro (Generic AI Editors)

Cursor and similar editors typically look for configuration in a specific project or global location.

* **Project Specific:** Copy `mcp_config.json` content to `.cursor/mcp.json` in your project root.
* **Global Configuration:** Copy `mcp_config.json` content to `~/.cursor/mcp.json`.

**Recommended Tweak for Cursor:**
Cursor supports an `envFile` property. You can add this to each server block to load your `.env` directly:

```json
"server-name": {
  "command": "...",
  "envFile": "${workspaceFolder}/.env"
}
```

### 2. Antigravity (Gemini)

* **Path:** `~/.gemini/antigravity/mcp_config.json`
* **Usage:** Automatically loads all servers defined in the `mcpServers` block.
* **Env Vars:** Supports `${VAR_NAME}` substitution from the active `.env` file.

### 3. VSCode (Roo Code / Cline)

* **Path:** `%APPDATA%/Code/User/globalStorage/rooveterinaryinc.roo-cline/settings/mcp.json`
* **Integration:** Roo Code manages its own config. To leverage this unified setup, you can manually merge the `mcpServers` block from `mcp_config.json` into Roo's settings file.
